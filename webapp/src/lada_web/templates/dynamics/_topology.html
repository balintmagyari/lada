Chain topology

.npz files carry no atom ids. Atom order is assumed to match ascending atom ID, 0-indexed. Reading a LAMMPS data file is the surest way to get this right: it states the chains outright, and because the two files are lined up by atom-id order it has to describe the same number of atoms as the trajectory.

How many chains the trajectory holds.
Every chain has the same number of beads.
Where the chains start in the coordinate array. Leave it at 0 unless other particles come first.
The chains come from the molecule ids, or from the Bonds section when the file has no molecule column. Solvent and other single beads are left out. Only the topology is read; the coordinates in this file are ignored.
Reading the data file…
One chain per line: head,tail or the full bead list. Separate the indices with commas or spaces. Lines starting with # are ignored.
