Read and analyse LAMMPS output in the browser

Every calculation below works the same way, and each one says which file it needs before you open it.

  1. Upload one simulation file and set the physical parameters the calculation needs.
  2. Calculate, and read the result as a table with a plot where one helps.
  3. Download the full table as CSV, or as a pgfplots data file you can drop straight into a LaTeX figure.

Files are processed in a temporary folder and deleted as soon as the response is sent. Nothing you upload is stored on the server, so a download recomputes the result from the file you send with it.
