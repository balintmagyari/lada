Set before including: - regime_fields: comma-separated per-regime field names (e.g. "files,time_per_frame" or "files" for the ACF-file-only rheology pages, whose spacing comes from the file itself). - regime_shared_fields: comma-separated field names sent unchanged with every regime. - regime_view_url: the per-regime endpoint to call (for dynamic-moduli this is /api/rheology/stress-relaxation, not the page's own endpoint — see regime_merge_kind). - regime_merge_url, regime_merge_kind ("dynamics" | "rheology-gt" | "rheology-moduli"). - regime_value_column, regime_y_label, regime_title: dynamics merge-request fields. - regime_download_stem. #}
Additional regimes

Add a regime for each non-overlapping time window your data was collected in (for example fast / mid / slow). Each regime can itself hold several files to average, the same way the field above does. Every other field on this page (chain topology, volume, temperature, fit settings) is shared across every regime.
