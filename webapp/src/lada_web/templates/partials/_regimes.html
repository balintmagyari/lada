Additional regimes

Add a regime for each sampling rate your data was collected at (for example fast / mid / slow). Each regime can itself hold several repeat files to average, the same way the field above does. Where regimes cover the same lag time, the one that sampled it most finely is used, so runs that all start at time zero combine into one curve. Every other field on this page (chain topology, volume, temperature, fit settings) is shared across every regime.
